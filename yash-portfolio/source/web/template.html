What happens when the machine powers on

There is no Linux or Windows underneath. The computer reads 512 bytes from the disk and those bytes bring up everything else. This is the real boot sector from the disk image.

  1. The BIOS reads sector zero

    It copies the first 512 bytes of the disk to memory address 0x7C00 and checks that the last two bytes are 55 AA. That signature is what makes a disk bootable.

  2. The bootloader loads the kernel

    It reads the kernel one sector at a time, so it never trips over a track boundary. The kernel is {{KERNEL_BYTES}} bytes ({{KERNEL_SECTORS}} sectors) and lands at 0x10000.

  3. The CPU switches to 32-bit mode

    The bootloader builds a global descriptor table, sets bit 0 of CR0, and jumps into protected mode. Then it calls kmain.

  4. C takes over and talks to the hardware

    It loads its own colour palette into the VGA chip, writes text straight into video memory at 0xB8000, reads keys from port 0x60, keeps time with the timer chip, and beeps through the PC speaker.
